Projects & files

A project is one self-contained folder: the song, its 16 patterns, every sample and wavetable it uses. Nothing is hidden - it's all visible in the Files app.

The Projects screen

  • Projects list by last edit, most recent first; the active one wears a green check. Tap to load - the app jumps straight to Perform.
  • Every project carries a color square. Tap it to pick from the theme palette; the color shows beside the project name in the app header. Recoloring is cosmetic - it never reorders the list.
  • ＋ creates a new project (carrying over your current tempo). Swipe a row for Delete, Rename or Duplicate - duplicating copies the whole folder, samples included, so the copy owns its files.
  • Renaming a project renames its folder to match.
  • On a first launch the bundled Factory project loads - a ready-to-play kit built entirely from factory content.

Autosave and undo

  • Every edit autosaves a couple of seconds after you pause; switching projects flushes immediately. There is no save button to forget.
  • Undo/redo covers the whole project - trigs, locks, patterns, track setups, pools, slices, FX settings, morphs, the song chain, even MIDI bindings - 50 steps deep, with rapid edits coalescing into one. Transient things (DJ FX, app settings) sit outside it, and deleting a project can't be undone.

Sound presets

Presets are rig-level - shared across every project. Save one from any track's setup drawer; load one from Browse Presets.

  • A preset stores the device, its complete parameter set, the 8 knob slots, both LFOs with their links and depths, the track's default note / velocity / gate - and for sampler presets, the audio file itself with its slices.
  • Preset audio is stashed in a shared library, so loading a preset in another project imports its sample into that project's pool - the +Drive idea.
  • Organize with #tags (picked from a checklist - kick, snare, bass, lead, pad and friends, plus your own). Search matches names, sample names and tags; #term searches tags only.

On disk

Everything lives under On My iPhone → HeartBeat in the Files app:

FolderHolds
Projects/<Name>/project.json plus the project's samples, and its Wavetables/ subfolder - one portable unit you can copy out whole.
Presets/One JSON per sound preset, plus the preset audio library (Samples/, Wavetables/).
Factory/The shared factory kit and wavetables - deterministic, self-healing, never copied into projects.
Bindings/Exported MIDI-binding files.
  • Sample references inside a project are folder-relative, so renames and copies never break them.
  • Imports (samples, wavetables) copy into the project folder - deleting a pool slot leaves the file on disk for other projects.
