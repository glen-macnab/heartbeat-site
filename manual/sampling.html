Sampling

Every project carries its own 128-slot sample pool and 128-slot wavetable pool. Record into them, import into them, slice what's there - it all lives inside the project folder.

The sample pool

  • 128 numbered slots per project - the slot numbers are what the sampler's SAMPLE knob (and p-locks) address, so they never shift: deleting leaves a hole in place and the next import fills the first hole.
  • Tap a row to assign it to the current track and audition it; the speaker button auditions without assigning.
  • Import from any Files-app location: Choose Samples Folder…, browse subfolders, audition on tap, + to import. A file already in the pool shows a green badge and re-points instead of duplicating. Formats: wav, aif/aiff, mp3, m4a, flac, caf, aac, ogg. Samples decode up to 60 s.
  • Importing copies the file into the project's folder - projects stay self-contained.

Recording a sample

From the pool browser, choose Record a Sample… Two sources:

SourceRecords
ResampleThe master mix - everything you hear except the metronome. If the transport isn't running, hitting record starts it automatically.
Mic/InputThe microphone or a connected interface (pick the device, mono/stereo, and channel pair on multi-channel interfaces). Input is metered but not monitored back through the mix.
  • Snap to bar (on by default): while playing, the take starts and stops on the next bar line - a resampled loop comes out exactly bar-length. The level meter turns red above clipping range.
  • Takes run up to 60 seconds. Afterwards: name it (defaults count up as Resample 1, Sample 1, …), preview, then Add to Pool → Track N assigns it straight to the track you came from - or Discard.

The slice editor

With a track's sampler in SLICE mode, the scissors chip in the waveform header opens the slice editor.

  • Tap the waveform to add a marker · tap a marker to select it (it turns amber) · drag to move it · trash deletes the selected marker · Clear removes them all.
  • The GRID row (4 / 8 / 16 / 32 / 64) seeds an even chop you can then adjust by hand.
  • Slices are stored on the pool slot, so every track playing that sample shares them - and presets carry them along.
  • The region before your first marker counts as slice 1; an unsliced sample plays whole.
Tip Back on the waveform display, tapping a slice plays it through the track's voice and points the SLICE knob at it. The device menu's Linear / Random Slice Locks scatter slice choices across the pattern in one move.

The wavetable pool

  • 128 slots per project, browsed from the waveform header on a Wavetable track. Auditioning a table plays it linearly - you hear the morph sweep itself.
  • Import from any Files folder (wav, aif/aiff, flac, caf). Files follow the common wavetable convention - 2048-sample frames - and anything else loads as a single-cycle wave.
  • Eight factory tables are seeded automatically: Basic Morph, PWM, Harmonics, Sync, FM, Vowel, Bell, Digital.

Factory content

A 12-piece drum kit - kicks, snare, clap, closed and open hats, rim, three toms, ride and a sub bass - is synthesized to disk deterministically (circuit-modeled, byte-identical on every device) and added the first time a sampler track meets an empty pool. Factory files live in a shared folder outside your projects, and self-heal: if one goes missing it's re-rendered rather than playing silence.
